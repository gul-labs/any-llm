'@gullabs/xai': minor
---

xAI stream failures are never retried after output began, carry an estimated usage, and never discard a complete answer (ADR-040 Amendment A). New optional `transport.idleTimeoutMs`.

- **No retry after output.** A connection cut, a body that ends before the final event, a malformed body or a mid-stream `error` event that arrives after the first output event is `retryable: false` (`kind: 'server'`, or the `error` code's kind), with the transport error as `cause`. A reasoning call burns tokens before its first visible event and a retry repeats that spend. A failure before any output event stays retryable. A mid-stream `rate_limit_exceeded` is never retried. `retryMiddleware` therefore sends one request, not three, for a call cut after output. Node's own timers keep `kind: 'timeout'`.
- **Estimated usage.** Such a failure carries `error.usage`: input is the request length over 4, output is the received characters over 4, marked `usage.details.usage_estimated = 1`, priced `'estimated'` and never exact. It understates (hidden reasoning tokens and tool fees are not counted). Usage in a `response.created` / `response.in_progress` snapshot is no longer used. A failure after the final event carries that event's exact usage. A failure before output still has no usage and counts as an unpriced attempt.
- **Mid-stream `error` events are not known-free.** They set `mayHaveBilled` (new in `@gullabs/core`), so `rate_limited` and `bad_request` events count in `callCost.unpricedAttempts`.
- **Reconciliation never fails a call.** Once the final event has a response object, a disagreement between the events and the final object (an item id with two types, an event without `output_index`, a malformed `output`) is a warning and the final object is used; before, it was a retryable error and the call, its answer and its usage were lost and re-billed. The only malformed shapes that fail a call are a final event without a response object and a body that is not JSON. A bare `event: keepalive` frame and `data: [DONE]` are skipped; a typeless JSON frame is skipped with a warning. Items the final object omits are matched from the end of an id group and are never duplicated. `response.incomplete` is incomplete whatever its response object says. A terminal response without token counts is a typed non-retryable `server` error, not a `TypeError`, and any other failure to map a complete response is the same error carrying the response's exact usage. A search call whose `action.sources` differ between the stream and the final object (xAI reports them cumulatively) no longer produces a warning on every web search.
- **`transport.idleTimeoutMs`** (integer from 1, off by default) ends a stream that sends no bytes, heartbeat comments included, for that long, as a non-retryable `kind: 'timeout'` with `reason: 'transport_timeout'`. The client now reads the response body itself (the `openai` SDK still sends the request and classifies HTTP errors).
- **`transport.fetch` must return the request's `text/event-stream` response.** A `fetch` that buffers the answer into a JSON body (a record/replay or caching wrapper) fails every call with a non-retryable `bad_request` naming the cause; before, it failed as a retryable `server` error and repeated a real upstream call. Test a streaming failure by stubbing `transport.fetch` with a `text/event-stream` body; `makeFakeXai` replaces `responses.create` and does not exercise the stream.

What hosts must change:

- Do not raise undici's `bodyTimeout` and `headersTimeout` to the whole request deadline (the earlier advice). While events flow the body timer is moot and a stream sends its headers at once. Keep `bodyTimeout` near the longest quiet gap you measured and set `transport.idleTimeoutMs` to bound a half-open connection.
- Resubmit a call that failed after output began only knowingly: it was not retried because it may have billed. Read `error.usage` (estimated) for a lower bound of what it cost.
- A `transport.fetch` wrapper that returns a buffered JSON body must return the event stream instead.
